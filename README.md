
# Prestige Motors

Projeto desenvolvido para o Checkpoint 6 da disciplina de Web Development da FIAP.

## Sobre o projeto

A Prestige Motors é uma aplicação web demonstrativa de locação de carros importados.

O site apresenta uma página inicial, um catálogo de veículos e filtros por categoria.

## Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Git e GitHub

## Funcionalidades

- Navegação entre páginas
- Menu responsivo
- Exibição de veículos importados
- Filtros por categoria
- Cards reutilizáveis
- Interface adaptada para diferentes telas

## Estrutura do projeto

- src/components: componentes reutilizáveis
- src/pages: páginas da aplicação
- src/data: informações dos veículos
- public/images: imagens utilizadas no site

## Como executar

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm run dev

Para gerar a versão de produção:

npm run build

## Versionamento

O projeto utiliza as branches main e dev, além de branches específicas para cada tarefa.

As funcionalidades foram desenvolvidas com commits semânticos e integradas através de Pull Requests.

## Observações

Projeto acadêmico demonstrativo, sem integração com sistemas reais de reserva, pagamento ou consulta de disponibilidade.
